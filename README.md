# AA Packages

Full PHP + MySQL ecommerce build for AA Packages packaging boxes.

AA Packages is a responsive packaging ecommerce website for custom cake, pizza,
gift, perfume, mithai, and printed boxes. It includes product browsing, cart and
checkout flows, quote requests, customer accounts, order tracking, an admin
dashboard, and Cash on Delivery ordering.

## Production Entry Points

- The public storefront opens from the domain root: `/`.
- The private admin login opens at `/aapackagesadmin` and is never linked from the storefront.
- The legacy `/admin` path returns `404`.
- Select the target cPanel database in phpMyAdmin, then import `database/aapackages.sql`.
- Configure database credentials through cPanel environment variables or `includes/db.php`.
- Use PHP 8.1 or newer with PDO MySQL, fileinfo, sessions, and Apache `mod_rewrite` enabled.

## New Storefront Features

- The first-order popup stores subscribers in `discount_leads` and issues the working `WELCOME5` coupon.
- The offer opens automatically once per browser session; closing it reveals the circular 5% button for reopening.
- WhatsApp uses `AA_WHATSAPP_NUMBER` from the environment (digits only, including country code).
- Contact Us submissions are stored in `contact_messages`.
- Admin pages `/aapackagesadmin/leads` and `/aapackagesadmin/contact-messages` provide management, deletion, search, and lead CSV export.
- Admin page `/aapackagesadmin/pages` controls the public About and Contact page headings and introductory content; contact details remain under Settings.
- Admin sessions use a rolling 8-hour lifetime by default. Change it with `AA_SESSION_TIMEOUT`.
- Sessions are stored in the protected `storage/sessions/` directory to avoid host-level session path failures.

## Payment Method

## Security Notes

- Clean URLs are enabled through `.htaccess`, e.g. `/shop`, `/category/cake-boxes`, `/product/window-cake-box-2lb`, `/aapackagesadmin/dashboard`.
- Rate limits are configurable in `includes/config.php` under `RATE_LIMITS`.
- Forms use CSRF tokens, prepared PDO statements, strict validation helpers, and generic user-facing errors.
- Full error details are logged server-side under `storage/logs/app.log`.
- Uploads validate MIME type and image content, use random filenames, and `uploads/.htaccess` blocks executable files.
- Database credentials can be configured with `AA_DB_HOST`, `AA_DB_NAME`, `AA_DB_USER`, and `AA_DB_PASS`.
- There are no Composer/npm dependencies in this project, so no dependency advisory audit is required until packages are added.

## cPanel Readiness

- Upload the project contents into the domain document root so `index.php` is the first page.
- The SQL dump contains catalog data and site content, but no sample customers, orders, revenue, transactions, quote requests, or testimonials.
- Existing installations should import `database/migrations/2026_10_15_production_cleanup.sql` once.
- Set `AA_SITE_URL` to the final HTTPS domain for canonical SEO URLs and the sitemap.
- `robots.txt`, `sitemap.xml`, per-page metadata, canonical links, Open Graph tags, and structured data are generated by the application.
- Source directories, SQL files, logs, environment files, directory listings, and executable uploads are blocked by Apache rules.

## Structure

- `controllers/` MVC-style request handlers.
- `models/` PDO-backed domain models.
- `views/` frontend and admin templates.
- `includes/` database, application config, security, and shared helpers.
- `public/assets/css/` branded design system and admin CSS.
- `public/assets/js/` sliders, reveal animations, 3D banner parallax, AJAX cart drawer.
- `database/aapackages.sql` schema plus catalog and editable site content.
